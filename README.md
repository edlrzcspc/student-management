# Student Management System

## Project Description

The Student Management System is a web application that allows users to view and add student records. It also includes a search feature for finding students by student ID, first name, last name, or course.

## Technologies Used

- Node.js
- Express.js
- EJS
- MySQL
- HTML
- Git and GitHub

## Features

- View the student list
- Add a student
- Search students by ID, name, or course
- Store student records in a MySQL database

## Requirements

- Node.js and npm
- MySQL or MariaDB
- Git

## How to Run the Project

1. Install the required packages:

   `npm install`

2. Configure the MySQL database connection in `app.js`.

3. Make sure MySQL is running and the `student_management` database is set up.

4. Start the application:

   `node app.js`

5. Open `http://localhost:3000` in your browser.

## Database

The application uses a MySQL database named `student_management` with a `students` table.
